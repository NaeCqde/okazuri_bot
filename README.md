# オカズリBOT

日本語 | [English](README.en.md)

DLsite のレーベル(COMIC快楽天 など)の雑誌と、複数のサイトの作品を、Discord からまとめて検索する BOT です。
サイト: https://okazuri.nae.quest/ ・ [API ドキュメント](https://okazuri.nae.quest/dev) ・ [検索サーバー(okazuri-search-api)](https://github.com/NaeCqde/okazuri-search-api)

## コマンド

| コマンド | 内容 |
|---|---|
| `/search` | 作品名などで検索します。結果は合法・違法に分けて表示します。日本語・ローマ字・英語で探せます。`by_magazine`(雑誌で検索)をオンにすると、入力した作品が載った号の名前に直して検索します。結果が長いときは、続きを WEB の検索ページで見られます。 |
| `/magazine` | 作品名から、その作品が載っている雑誌の号を探します。入力中に作品名の候補が出ます。 |
| `/works` | 雑誌の号の名前から、その号の作品の一覧を出します。 |
| メッセージのメニュー「Search this」 | メッセージに貼られた作品ページのリンクから題名を読み取って、検索します。「Search this with option」では、雑誌で検索するかどうかを選べます。 |

[WEB の検索ページ](https://okazuri.nae.quest/search)では、複数の語を一度に検索し、グループや並び順を選べます。

# オカズリBOTの利用規約

このアプリ(BOT)は、以下の用途でのみ提供されています。

### ・教育目的

### ・著作者による違法アップロードの摘発の補助

あなたが違法行為に関与した場合、運営は一切の責任を負いません。

また、権利者様がこのサイトに対してリンク掲載の削除要請を行ったとしても承りかねます。

削除は、掲載先のサイトへご依頼ください。掲載先から削除された作品は、自動で確認され、このサイトの検索結果からも外れます。

このアプリ(BOT)を使用することにより、これらの条件に同意したことになります。
