API documentation

The public server of okazuri-search-api. No authentication.

Start

The base URL is https://okazuri.nae.quest/api/v1. Everything is a GET and answers JSON (/romaji and /health answer text). A bad request is a 422 with {"detail": "..."}.

curl "https://okazuri.nae.quest/api/v1/okazuri/search?q=快楽天+2026+11"

GET/api/v1/okazuri/search

Searches the works of the sites. The query is turned into romaji first, and the works whose title has all its words are answered. A query in Japanese also finds the works of its English title (translation), a query without Japanese the works of its Japanese title (translationJa).

Parameter
qThe words. Required, 1 to 300 characters. White space separates them.
liveoff: answer from the database only. diff (default): ask only the combinations that are missing or old. on: ask every site.
limitThe most results (1 to 100).
excludeSites to leave out, by name, separated by commas.
translatorauto (default), hitomi, google or none: whether the translated title is searched too, and where it is translated.
GET /api/v1/okazuri/search?q=快楽天+2026+7
{
  "input": "快楽天 2026 7",
  "query": "kairakuten 2026 7",
  "total": 12,
  "results": [
    { "website": "DLsite", "isLegal": true, "url": "https://www.dlsite.com/...",
      "title": "COMIC快楽天 2026年11月号", "titleRomaji": "comic kairakuten 2026 nen 11 gatsu gou" }
  ],
  "translation": { "text": "COMIC Kairakuten", "source": "Hitomi" },
  "sites": [ { "website": "DLsite", "status": "searched", "count": 30 } ]
}

GET/api/v1/okazuri/sites

The sites that can be searched, and whether each is searched now.

GET /api/v1/okazuri/sites
[ { "name": "DLsite", "isLegal": true, "support": "ready", "hasSearch": true, "japanese": true, "active": true } ]

GET/api/v1/hitomila/search

Searches only the sites other than Hitomi.La (the same shape as /okazuri/search).

Parameter
qThe words.
GET /api/v1/hitomila/search?q=nine+lives

GET/api/v1/{hitomila,google,auto}/translate

Translates a title: Japanese into English, English into Japanese. auto uses Hitomi.La, and Google Translate if that fails.

Parameter
qThe text. Required.
liveoff / diff (default) / force.
GET /api/v1/auto/translate?q=姉弟

GET/api/v1/romaji

The romaji of a Japanese text, as text/plain.

Parameter
qThe text. Required.
loanwordsromaji (default) or english: how a loanword spelled in hiragana is written.
GET /api/v1/romaji?q=チートアイテム管理局のお仕事
chiito aitemu kanrikyoku no oshigoto

Cache

Cloudflare keeps the successful (200) answers: 5 minutes for a search, an hour for the sites, a day for translations and romaji. live=on, errors and /health are not kept. See Cache-Control and cf-cache-status in the answer.

The exact specification is API.md (GitHub).
