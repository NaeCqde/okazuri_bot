オカズリBOT 検索API 追加
APIはじめに検索タイトル雑誌号の作品雑誌一覧サイト一覧翻訳ローマ字キャッシュ

API ドキュメント

okazuri-search-api の公開サーバーです。認証は要りません。

はじめに

ベース URL は https://okazuri.nae.quest/api/v1。すべて GET で、JSON(/romaji と /health はテキスト)を返します。不正なリクエストは 422 と {"detail": "..."} です。

curl "https://okazuri.nae.quest/api/v1/okazuri/search?q=快楽天+2026+11"

GET/api/v1/okazuri/search

各サイトの作品を検索します。クエリはまずローマ字にされ、題名のローマ字と全部の語が合うものを返します。日本語のクエリには英語訳(translation)、日本語を含まないクエリには日本語訳(translation_ja)の題名の作品も含まれます。各結果には title_english(英語のタイトル、英語 | 日本語 の英語側、または保存済みの翻訳)は {text, source} の形で、source は official(作品自身のタイトル。Hitomi.La のものも)か google(機械翻訳)です。なければ null です。このリクエストのために翻訳はしません。

パラメータ
q検索語。必須、1〜300 文字。空白で語を分けます。
liveoff: DB だけで答える。diff(既定): 未取得か古い組み合わせだけサイトに聞く。force: 全サイトに聞く。
limit1 回の結果の最大数(1〜100、既定 100)。
offset先頭から飛ばす件数(0〜10000、既定 0)。limit と合わせて、長い答えを 100 件ずつ読めます。
exclude除くサイトの名前(カンマ区切り)。
translatorauto(既定) / hitomi / google / none。翻訳の題名でも探すか、どこで訳すか。
GET /api/v1/okazuri/search?q=快楽天+2026+7
{
  "input": "快楽天 2026 7",
  "query": "kairakuten 2026 7",
  "total": 12,
  "total_legal": 9,
  "total_illegal": 3,
  "results": [
    { "website": "DLsite", "is_legal": true, "url": "https://www.dlsite.com/...",
      "title": "COMIC快楽天 2026年11月号", "title_romaji": "comic kairakuten 2026 nen 11 gatsu gou",
      "title_english": { "text": "COMIC Kairakuten 2026 November", "source": "google" } }
  ],
  "translation": { "text": "COMIC Kairakuten", "source": "Hitomi" },
  "sites": [ { "website": "DLsite", "status": "searched", "count": 30 } ]
}
試す
total はヒットした作品の実際の数で、total_legal と total_illegal は合法なサイトと違法なサイトの内訳です(足すと total)。どれも limit と offset では変わりません。
GET/api/v1/okazuri/title
作品ページの URL からタイトルを取り出します。まず保存済みの作品から、なければページを取得して読みます。URL に余計なパラメータが付いていても、同じ作品に当たります。
パラメータ
url作品ページの URL。必須、1〜10 回まで繰り返せます(パーセントエンコードしてください)。
liveoff: 保存済みだけ。diff(既定): 保存済み、なければページ。force: いつもページを取得。
GET /api/v1/okazuri/title?url=https%3A%2F%2Fwww.dlsite.com%2Fbooks%2Fwork%2F%3D%2Fproduct_id%2FBJ03044883.html
{ "total": 1, "results": [
  { "url": "https://www.dlsite.com/books/work/=/product_id/BJ03044883.html", "website": "DLsite",
    "title": "COMIC快楽天 2026年11月号", "title_japanese": "COMIC快楽天 2026年11月号",
    "title_romaji": "comic kairakuten 2026 nen 11 gatsu gou", "title_english": null,
    "source": "database", "error": null } ] }
試す


GET/api/v1/okazuri/magazine
作品名(完全一致)が載っている号を、新しい号から返します。同名の作品は複数返ります。
パラメータ
q作品名。必須、1〜300 文字。
limit最大件数(1〜50、既定 10)。
GET /api/v1/okazuri/magazine?q=作品名
{ "input": "作品名", "total": 1, "results": [ {
  "id": "BJ9", "title": "作品名", "url": "https://www.dlsite.com/...", "author": "作者", "position": 4,
  "magazine": { "id": "LBL1", "name": "COMIC快楽天" },
  "issue": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "https://www.dlsite.com/...", "date": 1793181281 } } ] }
試す


GET/api/v1/okazuri/works
号の名前(号の id でも可。完全一致)から、掲載作品を号の中の順に返します。
パラメータ
q号の名前。必須、1〜300 文字。
GET /api/v1/okazuri/works?q=COMIC快楽天 2026年07月号
{ "input": "COMIC快楽天 2026年07月号",
  "issue": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "...", "date": 1793181281 },
  "magazine": { "id": "LBL1", "name": "COMIC快楽天" }, "total": 1,
  "results": [ { "id": "BJ9", "title": "作品名", "url": "...", "author": "作者", "position": 4 } ] }
試す


GET/api/v1/okazuri/magazines
雑誌の一覧を名前順に返します。号の数 issues と、いちばん新しい号 latest が付きます。
GET /api/v1/okazuri/magazines
{ "total": 1, "results": [ { "id": "LBL1", "name": "COMIC快楽天", "issues": 120,
  "latest": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "...", "date": 1793181281 } } ] }
試す


GET/api/v1/okazuri/sites
検索の対象のサイトと、いま検索しているかを返します。
GET /api/v1/okazuri/sites
[ { "name": "DLsite", "is_legal": true, "support": "ready", "has_search": true, "japanese": true, "active": true } ]
試す


GET/api/v1/{hitomila,google,auto}/translate
題名の翻訳です。日本語の語は英語に、英語の語は日本語に訳します。auto は Hitomi.La、だめなら Google 翻訳。


パラメータ
q翻訳する語。必須。
liveoff / diff (既定) / force.


GET /api/v1/auto/translate?q=姉弟
試す


GET/api/v1/romaji
日本語のローマ字を text/plain で返します。
パラメータ
qテキスト。必須。
loanwordsromaji(既定) / english: ひらがなの外来語の書き方。
GET /api/v1/romaji?q=チートアイテム管理局のお仕事
chiito aitemu kanrikyoku no oshigoto
試す


キャッシュ
Cloudflare が成功(200)の応答を保持します。検索とカタログの検索は 5 分、サイト一覧は 1 時間、翻訳とローマ字は 1 日です。live=force、エラー、/health は保持されません。応答の Cache-Control と cf-cache-status で確認できます。


正確な仕様は API.md (GitHub).
