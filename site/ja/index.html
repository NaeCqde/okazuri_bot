複数サイトを一度に

DLsite などの合法サイトと、そのほかのサイトの結果を、合法・違法に分けて並べます。

権利者の発見を助ける

著作者が違法アップロードを見つけて、削除要請や訴訟などの対応に進むまでの時間を短縮することも、目的のひとつです。

日本語・ローマ字・英語

日本語の題名はローマ字と英語に、英語の語は日本語の題名にも当たって、取りこぼしを減らします。

雑誌のチェック

DLsiteに配信されているレーベルの最新号を毎日取り込んで、検索で見つけられます。

公開 API

同じ検索を、誰でも使える HTTP API として公開しています。 ドキュメント

使いかた

Discord で /search に探したい語を入れるだけです。雑誌の名前で探すときは by_magazine(雑誌で検索)をオンにします。

あなたが違法行為に関与した場合、運営は一切の責任を負いません。BOT を使うことで、この条件に同意したことになります。

また、権利者様がこのサイトに対してリンク掲載の削除要請を行ったとしても承りかねます。
削除は、掲載先のサイトへご依頼ください。掲載先から削除された作品は、自動で確認され、このサイトの検索結果からも外れます。
