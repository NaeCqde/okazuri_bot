API documentation

The public server of okazuri-search-api. No authentication.

Start

The base URL is https://okazuri.nae.quest/api/v1. Everything is a GET and answers JSON (/romaji and /health answer text). A bad request is a 422 with {"detail": "..."}.

curl "https://okazuri.nae.quest/api/v1/okazuri/search?q=快楽天+2026+11"

GET/api/v1/okazuri/search

Searches the works of the sites. The query is turned into romaji first, and the works whose title has all its words are answered. A query in Japanese also finds the works of its English title (translation), a query without Japanese the works of its Japanese title (translation_ja). Each result has title_english (the title if it is English, the English side of an English | 日本語 title, or a saved translation) is {text, source}, where source is official (the work's own title, Hitomi.La's too) or google (a machine translation); it is null when there is none. Nothing is translated for the request.

Parameter
qThe words. Required, 1 to 300 characters. White space separates them.
liveoff: answer from the database only. diff (default): ask only the combinations that are missing or old. force: ask every site.
limitThe most results of one request (1 to 100, default 100).
offsetHow many results to skip at the head (0 to 10000, default 0). With limit it reads a long answer 100 at a time.
excludeSites to leave out, by name, separated by commas.
translatorauto (default), hitomi, google or none: whether the translated title is searched too, and where it is translated.
GET /api/v1/okazuri/search?q=快楽天+2026+7
{
  "input": "快楽天 2026 7",
  "query": "kairakuten 2026 7",
  "total": 12,
  "total_legal": 9,
  "total_illegal": 3,
  "results": [
    { "website": "DLsite", "is_legal": true, "url": "https://www.dlsite.com/...",
      "title": "COMIC快楽天 2026年11月号", "title_romaji": "comic kairakuten 2026 nen 11 gatsu gou",
      "title_english": { "text": "COMIC Kairakuten 2026 November", "source": "google" } }
  ],
  "translation": { "text": "COMIC Kairakuten", "source": "Hitomi" },
  "sites": [ { "website": "DLsite", "status": "searched", "count": 30 } ]
}
Try it
total is the real number of hits, and total_legal and total_illegal split it by the legality of the site (they add up to total). None of them changes with limit or offset.
About dates: this API does not return the day a work was uploaded or published. It does not return the time the server saved it (when the crawler or a search first found it) either. is_new only says that this request was the first to find the work; it says nothing about when it was uploaded. Do not use it as the date a work appeared, or as evidence for a takedown request.
GET/api/v1/okazuri/title
Reads the title of a work from the URL of its page: from the saved works first, and from the page when it is not saved. Extra parameters in the URL still find the same work.
Parameter
urlThe URL of a work page. Required, 1 to 10 times (percent-encoded).
liveoff: saved works only. diff (default): saved, else the page. force: always the page.
GET /api/v1/okazuri/title?url=https%3A%2F%2Fwww.dlsite.com%2Fbooks%2Fwork%2F%3D%2Fproduct_id%2FBJ03044883.html
{ "total": 1, "results": [
  { "url": "https://www.dlsite.com/books/work/=/product_id/BJ03044883.html", "website": "DLsite",
    "title": "COMIC快楽天 2026年11月号", "title_japanese": "COMIC快楽天 2026年11月号",
    "title_romaji": "comic kairakuten 2026 nen 11 gatsu gou", "title_english": null,
    "source": "database", "error": null } ] }
Try it


GET/api/v1/okazuri/magazine
The issues that printed a work (exact title), newest first. A title shared by several works gives several results.
Parameter
qThe title of the work. Required, 1 to 300 characters.
limitThe most results (1 to 50, default 10).
GET /api/v1/okazuri/magazine?q=作品名
{ "input": "作品名", "total": 1, "results": [ {
  "id": "BJ9", "title": "作品名", "url": "https://www.dlsite.com/...", "author": "作者", "position": 4,
  "magazine": { "id": "LBL1", "name": "COMIC快楽天" },
  "issue": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "https://www.dlsite.com/...", "date": 1793181281 } } ] }
Try it


GET/api/v1/okazuri/works
The works of an issue, by its name (or its id; exact), in the order of the issue.
Parameter
qThe name of the issue. Required, 1 to 300 characters.
GET /api/v1/okazuri/works?q=COMIC快楽天 2026年07月号
{ "input": "COMIC快楽天 2026年07月号",
  "issue": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "...", "date": 1793181281 },
  "magazine": { "id": "LBL1", "name": "COMIC快楽天" }, "total": 1,
  "results": [ { "id": "BJ9", "title": "作品名", "url": "...", "author": "作者", "position": 4 } ] }
Try it


GET/api/v1/okazuri/magazines
Every magazine by name, with the number of its issues (issues) and its newest issue (latest).

{ "total": 1, "results": [ { "id": "LBL1", "name": "COMIC快楽天", "issues": 120,
  "latest": { "id": "BJ2", "name": "COMIC快楽天 2026年07月号", "url": "...", "date": 1793181281 } } ] }
Try it


GET/api/v1/okazuri/sites
The sites that can be searched, and whether each is searched now.
GET /api/v1/okazuri/sites
[ { "name": "DLsite", "is_legal": true, "support": "ready", "has_search": true, "japanese": true, "active": true } ]
Try it


GET/api/v1/{hitomila,google,auto}/translate
Translates a title: Japanese into English, English into Japanese. auto uses Hitomi.La, and Google Translate if that fails.


Parameter
qThe text. Required.
liveoff / diff (default) / force.


GET /api/v1/auto/translate?q=姉弟
Try it


GET/api/v1/romaji
The romaji of a Japanese text, as text/plain.
Parameter
qThe text. Required.
loanwordsromaji (default) or english: how a loanword spelled in hiragana is written.
GET /api/v1/romaji?q=チートアイテム管理局のお仕事
chiito aitemu kanrikyoku no oshigoto
Try it


Cache
Cloudflare keeps the successful (200) answers: 5 minutes for a search and a catalogue lookup, an hour for the sites, a day for translations and romaji. live=force, errors and /health are not kept. See Cache-Control and cf-cache-status in the answer.
